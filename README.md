# FAQ Accordion

A responsive and accessible FAQ accordion built as part of a [Frontend Mentor](https://www.frontendmentor.io/) challenge.

## Features

- Expand and collapse frequently asked questions.
- Responsive design for different screen sizes.
- Interactive functionality using JavaScript.
- Keyboard accessibility and screen reader support.

## Built With

- HTML5
- CSS3
- JavaScript

## What I Learned

This project helped me practice JavaScript event handling, responsive layouts, and accessibility principles for interactive web components.
